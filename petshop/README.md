# Focinho Feliz Pet Shop

Site de um petshop fictício, feito para o projeto da disciplina (Fase 1). Nesta fase o site usa apenas HTML, sem CSS, Bootstrap ou JavaScript.

**Site publicado:** https://gabrieloiw.github.io/uniprojects/petshop/

## Como navegar

Todas as páginas têm a mesma estrutura:

- **Cabeçalho:** nome do petshop, endereço, telefone, horário de funcionamento e o menu com links para as quatro páginas.
- **Corpo:** o conteúdo de cada página, descrito abaixo.
- **Rodapé:** links de navegação, contato, autoria, créditos das fotos e link para este código-fonte.

## Páginas e funcionalidades

| Página | Arquivo | O que tem |
|---|---|---|
| Início | `index.html` | Apresentação do petshop, as três categorias de produtos (com links que levam direto a cada uma) e um resumo dos serviços. |
| Produtos | `produtos.html` | Dois produtos de cada categoria (Alimentação, Brinquedos e Acessórios), cada um com foto, descrição e valor. Os links no topo da página levam direto à categoria escolhida. |
| Serviços | `servicos.html` | Tabela com os serviços oferecidos: nome, descrição, valor e se o serviço tem tele-busca. Abaixo da tabela, como funciona a tele-busca. |
| Contato | `contato.html` | Endereço, telefone, WhatsApp, e-mail e horário de funcionamento. O e-mail abre o programa de e-mail do computador. |

**Tele-busca:** o petshop busca o pet em casa e o leva de volta depois do atendimento. Na página de Serviços, a última coluna da tabela indica quais serviços têm essa opção.

## Como abrir no computador

Baixe ou clone o repositório e abra o arquivo `index.html` em qualquer navegador. Não é preciso instalar nada.

## Estrutura dos arquivos

```
petshop/
├── index.html       página inicial
├── produtos.html    produtos por categoria
├── servicos.html    serviços e tele-busca
├── contato.html     contato e horário
├── README.md        este arquivo de ajuda
└── imagens/         fotos dos produtos
```
